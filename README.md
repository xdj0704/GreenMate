# 🍅 GreenMate — 番茄连续状态认知工作台

> 面向番茄生长环境的连续状态认知、趋势预测与多源证据分析系统。  
> 不做病害诊断、产量预测、农业控制决策——**只分析环境本身**。

---

## 功能概览

| 能力 | 说明 |
|------|------|
| 连续状态认知 | 识别稳态基线、渐进漂移、外部扰动等环境状态 |
| 趋势预测 | 不等阈值超限才告警，基于历史时序识别变化方向 |
| 多源证据分析 | 严格区分5类证据，显式处理分歧与缺失 |
| 可信降级 | 证据不可用时明确标注限制，拒绝虚构补全 |
| LLM自然语言解释 | 仅基于结构化JSON结果做通俗解读，不生成新事实 |

## 快速开始

### 安装依赖

```bash
pip install anthropic
```

> 项目核心逻辑（引擎、渲染、Web界面）均使用 Python 标准库，无额外依赖。  
> 仅 LLM 自然语言解释层需要 `anthropic` 包。

### 配置 API Key

```bash
export ANTHROPIC_API_KEY="sk-ant-..."   # Linux / macOS
set ANTHROPIC_API_KEY=sk-ant-...        # Windows CMD
$env:ANTHROPIC_API_KEY="sk-ant-..."     # Windows PowerShell
```

### 运行

```bash
# 运行单个场景（S1-S5）
python main.py S2

# 一键遍历全部5个场景，生成 Markdown 报告
python main.py ALL

# 启动 Web 界面（http://127.0.0.1:8765）
python main.py web

# 启动 Web 界面但不自动打开浏览器
python main.py web --no-browser
```

## 五大测试场景

| 场景 | 名称 | 核心验证点 |
|------|------|-----------|
| **S1** | 稳态基线 | 环境长期稳定时**不制造虚假告警** |
| **S2** | 渐进漂移 | 阈值未超限时通过**趋势**提前告警 |
| **S3** | 外部扰动 | 本地稳定时将**未来外部天气**纳入风险 |
| **S4** | 多源证据分歧 | 多源矛盾时**显式表达不确定性**，不强行合并 |
| **S5** | 证据退化 | 证据不可用时**可信降级**，拒绝虚构补全 |

## 推理链路

```
连续观察 → 状态识别 → 演化理解 → 短时预测 → 多源取证 → 综合结构化判断 → 边界校验（可信降级）
```

## 五类证据（严格区分，禁止混合）

| 类型 | 说明 |
|------|------|
| ① 历史观测数据 | 已发生的传感器时序事实 |
| ② 当前实时观测 | 温湿度光照瞬时值 |
| ③ 外部天气证据 | 未来预报，尚未发生 |
| ④ 专业知识证据 | RAG检索的番茄环境专业资料，带引用来源 |
| ⑤ 模型预测 MODEL_OUTPUT | 独立辅助证据，不能覆盖事实观测 |

## 输出格式

每次运行输出：

1. **运行元信息** — run_id、analysis_time、location、激活场景
2. **结构化JSON判断** — current_state、attention_level、evidence_list 等
3. **四大视图**
   - 视图A：状态总览（现在怎样？）
   - 视图B：状态演化（为什么变成这样？）
   - 视图C：证据空间（凭什么这样判断？）
   - 视图D：场景回放与对比（判断是否可验证？）
4. **自然语言综合解释** — 严格基于JSON，不新增事实

## 硬性边界

- ✅ 分析温室环境本身（温度、湿度、光照、CO₂等）
- ✅ 识别环境状态、趋势、外部扰动风险
- ❌ 不输出番茄病害诊断
- ❌ 不输出植株长势判断
- ❌ 不输出施肥用药建议
- ❌ 不输出产量预测
- ❌ 不输出农业控制决策
